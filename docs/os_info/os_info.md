# Observing Strategy Analysis

Observing strategies are generated by the LSST scheduler (https://github.com/lsst-sims/legacy_sims_featureScheduler) in the form of an sqlite database containing a list of observations (LSST pointings) characterized by a set of parameters (RA, Dec, exposure time, observing conditions,...). The map relating LSST pointings and observations on the celestial sphere ((RA, Dec) positions) is generated using gnomonic projections of LSST focal planes centered on LSST pointings. The celestial sphere is pixellized using healpix with nside=64 (WFD) and nside=128 (DDFs).

There are thus two possible ways to analyze observing strategies, that is to estimate OS parameters (cadence of observation, number of visits, exposure time, observed area, ...):

## [Pointings analysis](docs/os_info/pointing_analysis.md)
OS parameters are estimated using LSST pointings. This is especially suitable for DDFs where the area of observation is clearley defined.

## Pixel analysis
OS parameters are estimated for each pixel of the celestial sphere. This approach is more precised that the pointing analysis but requires also more computing time.
