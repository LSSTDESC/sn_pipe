## Usage:  plot_scripts/os_info/plot_os_info.py

<pre>
Script to plot pixel level OS infos

Options:
  -h, --help       show this help message and exit
  --dbName=DBNAME  dbName to process [test_newb]
  --dbDir=DBDIR    dbDir of the OS to process [../test_metric]
</pre>

## example

python plot_scripts/os_info/plot_os_info.py --dbName=baseline_v4.0_10yrs --dbDir=../test_metric will lead to a display of figures of the file ../test_metric/baseline_v4.0_10yrs.hdf5
