# SN survey plots



## Usage: plot_scripts/cosmology/plot_cosmo_survey_sn.py [options]

<pre>

Script to plot the surveys used to estimate cosmo params

Options:
  -h, --help         show this help message and exit
  --dataDir=DATADIR  Data dir [../test_durvey]
  --config=CONFIG    config file [config_ana_selplot.csv]
  --fields=FIELDS    data type [COSMOS,XMM-LSS,CDFS,ELAISS1,EDFS_a,EDFS_b]

</pre>

## Example

python plot_scripts/cosmology/plot_cosmo_survey_sn.py --dataDir=../test_survey
